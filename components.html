Check these before you buy

Close substitutes can fail. Match these exactly.

microSD card64 GB minimum, 128 GB advised, UHS-I, A2
USB-serial adapters ×2CH343 / CH9102 class (1a86:55d3), one per bus

Plug both USB-serial adapters directly into the Jetson.

Behind a hub they often fail to show up. Use the hub for the keyboard only.

In the US, plan to make your own servo cables.

Long 3-pin cables are hard to find, so order 3-pin connectors and a crimping tool with the servo wire.

3D-printed parts

Print every part in PLA, except the gripper fingers, which are TPU.

1. Download the print file

3MF XLeRobot-Pro print projectEvery printed part on 7 plates, print settings applied · 10.8 MB Download

Opens in PrusaSlicer, set up for a Prusa CORE One.

Optional extras

  • Wrist-camera mount (opens in a new tab) from TheRobotStudio
  • Arm base STEP (12.9 MB), only if you want to change the design

2. Print settings

The 3MF already applies these. You only need them if you slice the parts some other way.

4 perimeters on every arm part High-Shell
2 perimeters on everything else Default

Every part: 0.20 mm layers and 15% infill.

3. Printing rules

  • Print structural parts upright where you can.
  • In a humid room, dry the PLA at about 45 °C for 8 hours first.
  • If the wheels don't sit level, scale the wheel-base connector in Z only.
  • Use PLA and TPU only; other filaments were not tested.

4. Check you have everything

  • Two SO-101 follower arms (leader arms are only for leader-follower teleop)
  • The neck and head
  • The omni-wheel base
  • The Jetson open frame
  • Fin-Ray gripper fingers, in TPU95A
  • Optional: one wrist-camera mount per arm, with a 32×32 mm USB camera, two M3×8 screws, and two M3 hex nuts
